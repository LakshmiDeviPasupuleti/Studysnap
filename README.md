📚 StudySnap

🧠 Overview
StudySnap is a smart productivity application designed to help students stay focused using Pomodoro-based study sessions combined with real-time focus monitoring and adaptive feedback. The system not only tracks attention levels but also actively intervenes when distractions are detected, ensuring disciplined and effective study habits.

🚀 Key Features
⏱️ Pomodoro-Based Study Sessions – Structured work and break cycles
👁️ Real-Time Focus Detection – Monitors user attention continuously
🚨 Smart Alert System – Warns users instantly when distraction is detected
🔒 Auto-Termination Control – Closes the application after repeated lack of focus
📊 Live Performance Graph – Updates every 2 seconds to reflect focus trends
🤖 Adaptive Cycle Adjustment – Dynamically modifies session durations based on performance

🎯 Objectives
Improve student focus and productivity
Provide real-time feedback on attention levels
Encourage disciplined study behavior
Visualize performance trends for self-improvement
Automate study cycle optimization

🧩 System Modules
⏳ Sprint Timer
Manages Pomodoro-style work and break sessions, ensuring structured study intervals.
👁️ Focus Detection Module
Continuously tracks whether the user is attentive. If the user looks away (e.g., sideways or downward), the system identifies it as a distraction.
🚨 Alert & Discipline System
Displays warning: “You are not focused, please concentrate.”
Allows up to 3 warnings
After 3rd warning → automatically closes the application
📊 Live Performance Monitoring
Updates every 2 seconds
Displays:
📈 Increased focus
📉 Decreased focus
➖ Stable performance
Provides real-time productivity insights
🔄 Adaptive Cycle Adjuster
Analyzes focus trends and adjusts future study and break durations accordingly.
📈 Session Graph UI
Visual dashboard showing focus efficiency and session analytics over time.

⚙️ Workflow
User starts a study session
Timer initiates a focused work cycle
Focus detection runs continuously
If distraction is detected → warning alert is shown
After 3 warnings → application terminates
Performance graph updates every 2 seconds
System adapts future sessions based on performance
